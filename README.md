## 🚀 Quick Start

```bash
git clone https://github.com/anshul2414/cyberscan-pro-v2.git
cd cyberscan-pro-v2
pip install -r requirements.txt
python app.py
# Open http://localhost:5000 — no login required!
```

### 🐳 Docker
```bash
docker-compose up -d
# Open http://localhost:8080
```

### 🪟 Windows
```bat
run.bat
```
